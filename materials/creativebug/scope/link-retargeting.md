# 链接改投：偏离源站的地方（用户已拍板保留）

## 决定

用户口径：「除非你能再补齐有卡片但是显示 404 的页面，不然就采用我这个。」
补齐那些页面需要从源站重新采集，本机直连是 WAF 403，只能靠人的浏览器会话，
即"扩展数据库"——用户已明确不做。因此**保留改投**。

## 一、未采集课程链接 → 真实课程页（40235 处）

源站的 Related Classes / 列表条目指向课程 X；X 因 N=12 截断未被采集。
此前改投到边界页 `/_clone/out-of-scope`，点下去是死胡同。

现改投到一门**真实存在且内容饱满**的课。选择时若能拿到相近的池子就优先用
（页面自身的子类 → 大类 → slug 匹配），拿不到就退回全站池；取值按原路径 CRC32，
保证同一条链接每次构建落到同一门课（构建可复现）。替身池按"有讲师、单元数多"排序。

**明确不保证落点与链接文字同类。** 实测抽 60 个子类页 1882 条可判定链接，
同子类 24%、同大类 32%、跨大类 43%（该分母混有源站本来就跨类的真实链接，
不单指替身，故不能据此评价算法优劣）。

用户 2026-08-30 裁定：目标是"点进去有东西"，不要求同类
（「推荐的也不一定是同类课程，我感觉只需要点进去有东西就可以了」）。
源站的推荐本身也不保证同类，因此"同子类优先"从来不是源站语义，
而是先前文档自行引入的描述 —— 已在此更正。

**这是与源站的差异**：链接文字写着课程 X，点进去是课程 Y。
取舍是「每个条目都点得动」压过「标签与落点一致」，由用户裁定。
要退回忠实版本，把 `build_pages.py` 中 `substitute_class` 的调用去掉即可。

## 二、CTA 落点纠正（5265 处）

`Start Free Trial` / `GET OFFER` / `VIEW MORE` 等按钮，源站指向的促销与订阅
地址没被采集，一律落到边界页。按钮文案即意图，据此接回站内已有的对应页面：

- 试用类文案 → `/trial/create-account`
- 浏览类文案 → `/classes`

**这一条不算内容捏造**：源站这些按钮本来就是去试用注册页/目录页的，
我们只是把落点接回它本该到的、且我们确实采到的页面。

## 三、仍保留边界页的（29039 处）

站外导航、源站 403 路径、博客等确实没有对应内容的目标。
其中 `Visit Blog`：源站有博客但未采集，不能凭空造，保持边界页。

## 四、off-canvas 抽屉恢复默认收起

不是改投，是修复：`.offcanvas` 在源站未打开时是收起的（Bootstrap 语义），
脚本剥离后这条状态丢失，面板摊在页面流里，`/classes/search` 底部因此变成
一列 450px 宽、左截右空的卡片。补回 `.offcanvas:not(.show){display:none}`
后页面高度 7797 → 2594，卡片回到正常网格。**这条是向源站靠拢，不是偏离。**
