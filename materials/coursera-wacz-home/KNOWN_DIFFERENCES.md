# Coursera WACZ homepage — known differences

- The supplied WACZ contains only the homepage. Search, authentication, course,
  account, enrollment, checkout, and learning destinations are not reconstructed.
- Analytics, advertising pixels, session replay, identity-provider scripts,
  consent transmission, and other remote behavior captured in the WARC are
  intentionally omitted.
- The archived public content and presentation images are retained locally, but
  the production JavaScript application is replaced by small deterministic
  frontend code. Promotional cards switch only after user input and never autoplay.
- The WACZ does not contain a screenshot. `source-evidence/home-reference.png`
  was generated by fulfilling browser requests from archived WARC responses;
  unavailable font fallbacks and ambiguous repeated POST responses can affect
  dynamic sections, so it is a diagnostic reference rather than an acceptance gate.
- The manifest format requires a backend-model path. The included draft model is
  an inactive authoring contract only; this homepage has no backend runtime,
  database, account, email, or payment capability.
- The responsive mobile layout is a safe local derivation because the archive
  records one desktop homepage state.
- No public deployment, publication, redistribution, or rights determination is
  authorized by this local reconstruction or its diagnostic reports.
- Static WebsiteBench diagnostics complete on this machine. The generic live
  diagnostic cannot start its candidate because the host sandbox blocks its
  isolation/socket setup (`Operation not permitted`; an earlier host preflight
  reported `IsolationUnavailable`). Equivalent loopback Uvicorn + Playwright
  interaction tests remain available and do not weaken or bypass the repository
  sandbox contract.
